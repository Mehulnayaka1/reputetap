# ReputeTap Acrylic Standee Print & Graphic Template Guide

## Graphic Design Specifications
- **Canvas Size**: 100 mm (W) x 150 mm (H) + 3 mm bleed on all sides (Total trim canvas: 106 mm x 156 mm).
- **Resolution**: 300 DPI or vector format (`.AI`, `.EPS`, `.PDF`, `.SVG`).
- **Color Mode**: CMYK for high-fidelity UV flatbed printing.

---

## Typography & Color System
- **Primary Font Family**: `Plus Jakarta Sans` or `Roboto` (Bold / SemiBold).
- **Google Star Yellow**: `#FBBC05` / CMYK: (0, 26, 100, 0)
- **Google Accent Blue**: `#4285F4` / CMYK: (73, 46, 0, 0)
- **Obsidian Dark**: `#111827` / CMYK: (76, 68, 64, 80)
- **Studio White**: `#FFFFFF` / CMYK: (0, 0, 0, 0)

## Layer Structure & UV Print Guidelines
1. **Background Layer**:
   - Crisp solid white backing vector box to ensure maximum contrast for QR code scanning.
2. **Branding Layer**:
   - High-resolution SVG/PNG logo of the client scaled to fit within a 70mm x 28mm bounding box.
3. **Instructional Callout**:
   - `TAP PHONE HERE` icon centered with minimum 12pt bold sans-serif text.
4. **QR Code Layer**:
   - 35mm x 35mm high-contrast vector QR code targeting `https://reputetap.pages.dev/?placeid={PLACE_ID}&biz={BIZ_NAME}&phone={PHONE}&type={TYPE}` with 4-module quiet zone around edges.
5. **Footer Disclaimer**:
   - Standard verified partner badge & transparent non-gating management disclosure text.
